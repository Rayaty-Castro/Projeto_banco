Projeto de Banco de Dados: Clínica VetCare

Status: Concluído Deploy Cloud (Aiven)

1. Visão Geral do Domínio

O VetCare é um sistema relacional desenvolvido para eliminar problemas de inconsistência de dados em consultas veterinárias, prontuários, estoque e vendas de petshop.

2. Normalização Aplicada

  • 1FN: Atributos atômicos e eliminação de campos multivalorados.
  • 2FN: Eliminação de dependências parciais em chaves compostas (ex: item_venda).
  • 3FN: Eliminação de dependências transitivas (ex: dados de veterinário isolados da consulta).
  • 4FN: Tratamento de dependências multivaloradas independentes.

3. Arquivos do Repositório

Acesse as pastas do projeto para visualizar os scripts completos:

  • /scripts/data.sql - DML de carga inicial (5+ registros)
